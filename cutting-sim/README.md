# 2D 直交切削シミュレーター

工具と被削材の接触部で起きること（切りくずの生成、せん断域の温度・応力・ひずみ・ひずみ速度、切削抵抗）を
ブラウザ上で計算するソフトです。AdvantEdge のような切削プロセス解析を目標にした第一段で、
3軸加工シミュレーター（リポジトリ直下）とは独立しています。

## 使い方

```
cd cutting-sim
npm i
npm run build     # dist/index.html（単一ファイル、Web Worker 内蔵）
npm test          # 検証テスト（約 25 秒）
```

`dist/index.html` をブラウザで開き、条件を入れて「切削開始」を押します。標準条件（S45C、200 m/min、h = 0.1 mm）は
一般的な PC で 30〜40 秒ほどで 0.6 mm 切り終わります。

## 計算モデル（src/sph.js）

| 項目 | 内容 |
|---|---|
| 離散化 | 2D 平面ひずみ、更新ラグランジュ SPH（3次スプライン核、h = 1.2Δx）、陽解法 |
| 連続の式 | 標準 SPH の連続の式＋20 ステップごとの Shepard 密度フィルタ |
| 速度勾配 | 核勾配補正（L·M⁻¹）付き |
| 材料 | 体積は線形 EOS、偏差応力は Jaumann 速度の亜弾性、Johnson-Cook 則への radial return |
| 安定化 | Monaghan 人工粘性（α = β = 1）、Gray-Monaghan 人工応力（ε = 0.3）、XSPH（0.5）、引張圧力の上限 −2A |
| 熱 | 塑性仕事の 90 % を発熱（Taylor-Quinney）、摩擦熱の 50 % を被削材へ、Cleary-Monaghan 型の熱伝導（安定条件に合わせてサブサイクル） |
| 工具 | 剛体。すくい角、逃げ角、刃先丸みを持つ符号付き距離関数で接触判定。クーロン摩擦で、せん断流れ応力 σy/√3 を上限 |
| 境界 | 底面 3 層、終端 3 列、入口の切込みより下を固定。工具の後方 h + r より後ろの加工面は凍結（残留状態を保持し、自由表面の数値不安定を避ける） |
| 高速化 | 質量スケーリング：慣性による応力 ρ·ms·V² が A の 4 % になる倍率を自動選択（上限 1 万倍） |

## 検証（test/cutting.test.mjs）

| 確認内容 | 基準 |
|---|---|
| S45C、200 m/min、h = 0.1 mm、α = 5° の比切削抵抗 | 1,500〜2,800 N/mm²（中炭素鋼の便覧値 約 2,100）。標準解像度で約 2,040 |
| 切りくず厚さ比 | 1.3〜2.8（計算値 約 1.7〜1.8、せん断角 約 31°、Merchant の式 36.6°） |
| 最高温度 | 350〜1,000 °C（計算値 約 630 °C） |
| エネルギー収支 | 発熱量 / 工具がした仕事 = 0.7〜1.0 |
| 傾向 | すくい角 −5° → 15° で主分力が下がりせん断角が上がる、切削速度を上げるとすくい面温度が上がる |

## まだ扱っていないこと（今後の候補）

- 工具の温度場（工具内の熱伝導）と工具摩耗（Usui 式など）
- 延性破壊による切りくずの鋸歯状化（チタン、インコネル）、切りくずの分断
- 加工面の残留応力の評価（凍結領域の応力をそのまま取り出せるようにする）
- 旋削・フライス加工への拡張（切取り厚さが変わる断続切削）、3D 化
