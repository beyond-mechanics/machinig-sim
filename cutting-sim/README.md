# 切削シミュレーター（2D・3D）

工具と被削材の接触部で起きること（切りくずの生成、せん断域の温度・応力・ひずみ・ひずみ速度、切削抵抗、
工具の温度と摩耗、切りくずの割れと排出）をブラウザ上で計算するソフトです。直交切削と、エンドミル側面加工の1刃分、3D の傾斜切削とねじれ刃エンドミル、それに STL で取り込んだ任意の工具とワークを扱います。AdvantEdge のような切削プロセス解析を目標にした第一段で、
3軸加工シミュレーター（リポジトリ直下）とは独立しています。

## 使い方

```
cd cutting-sim
npm i
npm run build     # dist/index.html（単一ファイル、Web Worker 内蔵）
npm test          # 検証テスト（約 25 分）
```

`dist/index.html` をブラウザで開き、条件を入れて「切削開始」を押します。標準条件（S45C、200 m/min、h = 0.1 mm）は
一般的な PC で 30〜40 秒ほどで 0.6 mm 切り終わります。

## 表示（等高線・なめらか・粒子）

3D では同じ考え方を一段上げて、粒子の核関数の和の等値面（内部の 0.45 倍）を細かい格子（粒子間隔の半分）から surface nets で取り出し、なめらかな表面として陰影をつけて描きます（src/surface3d.js）。色は 1 次元のテクスチャから引くので、「等高線」では面の上でも色の帯の境目がくっきり出ます。計算中は表面を 0.4 秒ごとに作り直します。固定した粒子の多いところは暗く描きます。

2D の場は FE の後処理のような等高線図で表示します（src/fieldview.js）。各粒子の値を滑らかな核関数（半径 1.6 粒子間隔）で細かい格子に広げ、画面の画素ごとに補間します。核の和が内部の半分になるところを物体の縁にするので、切りくずや割れた破片の輪郭がはっきり出ます。「等高線」は 12 段の色と境目の細い線、「なめらか」は連続した色、「粒子」は粒子をそのまま描きます。ミーゼス応力と静水圧は粒子ごとのばらつきが大きいので、値だけ 1.6 倍広い核で平均します。工具の温度も同じ段で描きます。

## ワーク断面の取り込み（直交切削）

「被削材 › ワークの断面 › ファイルから取り込み」で、閉じた輪郭を DXF（LINE、ARC、CIRCLE、LWPOLYLINE、POLYLINE）、SVG（path、rect、circle、ellipse など）、CSV（x, y の列）から読み込みます。すべての閉じた輪郭を偶奇規則で塗るので、外形の内側の輪郭は穴になります。一番高い点を y = 0、左端を x = 0 に置き、刃先は y = −h を右へ進みます。下の面（3 粒子分）と右端、刃より下の入口面を固定します。切削長さは読み込み時にワークの幅 − 0.1 mm にします。粒子が 6 万個を超える大きさは受け付けません（解像度を下げるか、ワークを小さくしてください）。例：`examples/work_step_hole.svg`（0.04 mm の段差と Ø0.14 mm の横穴で断続切削）、`examples/work_chamfer.csv`（入口の 45° 面取り）。取り込んだワークでは残留応力は計算しません。

## 計算モデル（src/sph.js）

| 項目 | 内容 |
|---|---|
| 離散化 | 2D 平面ひずみ、更新ラグランジュ SPH（3次スプライン核、h = 1.2Δx）、陽解法 |
| 連続の式 | 標準 SPH の連続の式＋20 ステップごとの Shepard 密度フィルタ |
| 速度勾配 | 核勾配補正（L·M⁻¹）付き |
| 材料 | 体積は線形 EOS、偏差応力は Jaumann 速度の亜弾性、Johnson-Cook 則への radial return |
| 安定化 | Monaghan 人工粘性（α = β = 1）、Gray-Monaghan 人工応力（ε = 0.3）、XSPH（0.5）、引張圧力の上限 −2A |
| 熱 | 塑性仕事の 90 % を発熱（Taylor-Quinney）、摩擦熱の 50 % を被削材へ、Cleary-Monaghan 型の熱伝導（安定条件に合わせてサブサイクル） |
| 工具 | 剛体（並進＋回転）。すくい角、逃げ角、刃先丸みを持つ符号付き距離関数で接触判定。クーロン摩擦（すべり速度で変わる）で、せん断流れ応力 σy/√3 を上限 |
| 刃先形状（src/profile.js） | 標準のくさび形、ネガランド、チップブレーカ溝（ランド・円弧溝・ブレーカ壁）、取り込み（DXF の LINE/ARC/LWPOLYLINE/POLYLINE、SVG の path/polygon/polyline、CSV）。多角形の距離関数（バケット格子で近傍の辺だけ探索、頂点は擬似法線で内外判定）。開いた線は工具本体を補完。実効すくい角は刃先から 0.3〜1.0 h の輪郭の向き |
| 延性破壊 | Johnson-Cook 損傷則 D = Σ Δεp/εf(η, ε̇, T)。D = 1 から 1.5 で強度を線形に失い、割れた粒子は圧縮だけを伝え、XSPH も切る。損傷は平均応力が引張（η > 0）の内部粒子だけで進める（引張試験の定数を圧縮のせん断域に当てると切りくず全体が粉になるため。表面粒子は SPH の密度が欠けて偽の引張になるため除外） |
| 切りくずの排出 | 割れていない近接粒子のつながりで切りくず片を判定し、支持部とつながらない片を「分断」、刃先から max(1.2 mm, 12h) 離れた片を「排出」として除去。直交切削はカール半径（円の当てはめ）、エンドミルは刃が抜けた後も指定角度だけ追跡して排出速度と向きを出す |
| 工具の温度（src/toolheat.js） | 工具に固定した差分格子（刃先から約 1 mm、外周は室温固定）。摩擦熱の 50 % と接触熱伝達 hc = 10⁸ W/m²K で入熱。直交切削は後半の平均接触条件から定常温度を Robin 条件で推定 |
| 工具摩耗 | Usui 式 dW/dt = A·σn·Vs·exp(−B/T)、B = 5302 K、A は S45C 200 m/min でクレーター摩耗が数 µm/min になるよう仮に設定（要校正） |
| エンドミル（src/process.js） | 工具軸に垂直な断面、ねじれなし。前の刃の円弧と今の刃の円弧に挟まれた切取り厚さ h = fz·|cos β| を1刃分切削。アップ／ダウンカット。F/b = K·h + Ke の最小二乗で切削係数を同定 |
| 鋸歯状切りくず | Ti-6Al-4V に Calamaz ら（2008）の TANH 修正 Johnson-Cook 則（ひずみ軟化）。h/12 以上の解像度と弱めの人工粘性（0.3）で断熱せん断帯と鋸歯ができる |
| 境界 | 底面 3 層、終端 3 列、入口の切込みより下を固定。工具の後方 h + r より後ろの加工面は凍結（残留状態を保持し、自由表面の数値不安定を避ける） |
| 高速化 | 質量スケーリング：慣性による応力 ρ·ms·V² が A の 4 % になる倍率を自動選択（上限 1 万倍） |

## 加工面の残留応力（直交切削、試験的）

「残留応力」をオンにすると、圧力に熱膨張（3α ΔT）を入れ、被削材を 0.8 mm 以上の深さにして切削し、終わったら切りくずと未切削層を外して工具の接触を切り、加工面の凍結を解いて、全粒子を室温へ冷やしながら（毎ステップ 0.2 %）速度を減衰させて 5,000 ステップ落ち着かせる。そのあと定常部の深さ分布（σxx 切削方向、σyy 深さ方向）を出す。

S45C 200 m/min h 0.1 α5：表面 σxx +210〜+300 MPa（引張。和の順序が変わるだけでこの幅で動く）、深さ 40 µm で −15〜−80 MPa、その下はゆるい引張。表面が引張になるのは、熱い表層が膨張を抑えられて縮んだあと冷えて縮むため（熱膨張なしだと表面 −85 MPa の圧縮だけ）。文献の 1045 鋼（表面 +200〜+600 MPa、深さ 20〜80 µm に −100〜−300 MPa）と比べ、表面の引張は合うが、その下の圧縮は弱い。下の圧縮のピークは解像度・切削長さ・落ち着かせる長さで大きく変わる（h/12 ではほぼ 0）ので、表面の値と傾向の比較に使うこと。冷却は一様な一瞬の冷却で、熱伝導による実際の冷え方とは違う。

**凍結位置と収束（2026-10-20 見直し）**：以前は深さを工具の軌跡 −h から測っていたため、加工面が −h より上へ戻ると表面の粒子が数に入らず、凍結位置によって表面の値が +214 → −96 MPa と符号まで変わって見えていました。いまは実際の加工面（幅 2Δx の列ごとの一番上の粒子）から測り、残留応力モードでは加工面を工具の後ろ 3h + r で凍結します。

| 凍結位置（k·h + r） | 1 | 3 | 6 | 20（実質なし） | 20、h/12 |
|---|---|---|---|---|---|
| 表面 σxx [MPa] | +278 | −24 | −7 | −15 | −12 |
| 30 µm | +20 | −24 | −27 | −29 | −15 |
| 100 µm | +43 | +94 | +175 | +109 | +150 |

（S45C 200 m/min、h 0.1 mm、切削長 1.2 mm、h/8。切削長 0.6 mm でも k = 3・6 で表面 −5・−28。）k = 1（工具のすぐ後ろ）だけが外れで、荷重がかかったままの状態を閉じ込めた見かけの引張でした。k ≥ 3 なら凍結位置・切削長・解像度によらず ±25 MPa でそろうので、数値としては収束しています。ただし収束した値は、測られている 1045 の加工面（表面 +200〜+600 MPa の引張、その下に −100〜−300 MPa の圧縮）と合いません。表面の引張は表層 10〜20 µm の急な温度勾配から、圧縮は刃先丸み（10 µm）でこすられる層から生まれますが、h/8 の粒子間隔 12.5 µm ではどちらも粒子 1 個分です。定量的に合わせるには加工面の近くだけ細かい粒子が要ります（いまの solver は一様な粒子間隔のみ）。

## 摩耗した工具で再計算（直交切削）

計算後に「摩耗した工具で再計算」を押すと、工具表面の摩耗速度（Usui 式）× 時間だけ表面を工具の内側へ後退させた輪郭（`profile.js` の `wornProfile`、刃先付近は 2 µm ごとに再分割）に切り替えて、もう一度削る。繰り返すと摩耗が進む様子を段階的に追える（毎回その形での摩耗速度を使う）。摩耗係数 Aw は仮の値なので時間は目安。

S45C 200 m/min h 0.1：新品 → 5 分 → 10 分で kc 2,024 → 2,107 → 2,143 N/mm²、Ft 64 → 69 → 76 N、切りくず厚さ比 1.75 → 1.94 → 1.99、せん断角 30.9 → 28.0 → 27.7°、工具最高 547 → 507 → 484 °C。クレーターで実効すくい角は大きくなるが、刃先の後ろの段差と逃げ面摩耗で背分力が増え、切りくずが厚くなる。工具温度が下がるのは、クレーターで接触の中心が刃先から離れるため。

## 条件スイープ（直交切削）

画面下の「条件スイープ」で、h・切削速度・すくい角・刃先丸み・μ のどれか1つを変えて、値ごとに最後まで計算し、Fc・Ft・kc・φ・hc/h・温度を表と図にします（CSV 保存可）。裏の別ワーカーで動くので、上の計算と並行できます。h を変えるときは粒子間隔を固定し（h/解像度 を h ごとに比例させると相似な計算になり寸法効果が消える）、Kienzle 式 kc = kc1.1·h^(−mc) を当てはめます。

S45C 200 m/min α5、間隔 12.5 µm（すべり速度で変わる摩擦）：刃先丸み 10 µm で h 0.05/0.1/0.15/0.2 mm の kc 2,209 / 2,017 / 1,977 / 1,924 N/mm²（mc 0.10）、30 µm で 2,389 / 2,106 / 2,006 / 1,952（mc 0.15、Ft/Fc 0.46 → 0.35）。間隔を h/8 にそろえると 10 µm で 2,067 / 2,017 / 1,984（mc 0.03）、30 µm で 2,414 / 2,106 / 2,017（mc 0.13）。30 µm と 10 µm の差を幅あたりの力にすると h 0.05/0.1/0.2 で 17 / 9 / 7 N/mm で、h が丸みの 2 倍を切ると急に増える（実効すくい角が負になり、すき取りが効く）。このモデルの寸法効果はほぼ刃先丸みから来るので、実際の工具のホーニング（超硬チップで 20〜50 µm が多い）を入れると鋼の文献値（0.15〜0.25 程度）の下限に届く。JC 則にないひずみ勾配の硬化などは入っていない。間隔 12.5 µm では刃先丸み 10 µm が 1 粒子未満で、h 0.05 の kc は h/8 の計算より 7 % 高く出る（粗さの分）。

切削速度のスイープでは、工具寿命を逃げ面摩耗速度（Usui 式）に反比例とみて Taylor 指数 n（V·Tⁿ = 一定）を出す。摩耗係数 Aw は仮校正だが n はそれによらない。S45C h 0.1（すべり速度で変わる摩擦）：100/200/300/400 m/min で平均 μ 0.52/0.42/0.38/0.35、工具最高 459/535/593/620 °C、逃げ面摩耗 0.10/0.41/0.73/1.22 µm/min、n = 0.55（クレーターでは 0.47）。一定の摩擦のとき（0.56）とほとんど同じ。超硬の実測（0.2〜0.3 程度）より大きく、速度を上げたときの寿命の落ち方を緩く見積もる。n = 0.25 にするには 100 → 400 m/min で摩耗速度が 256 倍にならないといけないが、いまは滑り速度で 4 倍、温度の項（Bw = 5302 K、459 → 620 °C）で 3.7 倍。工具温度が実測（200 m/min で 650〜700 °C 程度）より 100 °C ほど低いことと、Usui が高温側（877 °C 以上）で使う大きな活性化温度の領域に届かないことが原因とみる。摩耗定数は測定値がないので変えていない。

## 3D 傾斜切削（src/sph3d.js）

「3D 傾斜切削」を選ぶと、切れ刃を傾斜角 λ だけ傾けた 3 次元 SPH（同じ JC 弾塑性・熱連成・質量スケーリング）で計算します。

- 側面「周期」（既定）：幅方向を周期境界にした無限に広い板。工具は切れ刃に直角な断面を保ったまま V(cosλ, 0, sinλ) で進むので、端の影響なしに流出角を見られる
- 側面「自由」：幅 b の板の端まで含めて計算（側面へのはみ出し、バリの傾向）
- 出力：主分力・背分力・送り分力、比切削抵抗、切りくず流出角 ηc、切りくず厚さ比、最高温度。表示はドラッグで回転、「中央断面」で幅中央の断面だけを表示
- 3D でも延性破壊（2D と同じ損傷則、切りくず片の追跡と排出）を計算する。工具温度・摩耗は、切れ刃に沿って平均した接触の熱と圧力を 2D の工具格子（toolheat.js）に入れて解く（傾斜切削は定常推定も）。解像度 h/5 で 1 ケース数分

| S45C、h 0.1 mm、垂直すくい角 5°、広い板、h/5 | λ 0° | 15° | 30° | 45° |
|---|---|---|---|---|
| 流出角 ηc | 0.0° | 15.0° | 32.8° | 46.4° |
| 横分力 / 主分力 | 0.00 | 0.17 | 0.33 | 0.55 |
| 比切削抵抗 kc | 2,093 | 2,140 | 2,072 | 2,159 |

Stabler の法則（ηc ≈ λ）は 45° まで ±3° で成り立ち、横分力は約 0.55〜0.6 tan λ、主分力は λ によらずほぼ一定です。

## 3D エンドミル（ねじれ刃、src/sph3d.js の mode 'helix'）

「3D エンドミル」は、厚さ ap の板の側面をねじれ刃の 1 刃で削る 3 次元計算です。

- 被削材は 2D エンドミルの断面（前の刃の削り跡と今の刃の間の三日月形の切取り部と、その外側の薄い帯）を軸方向に ap だけ積み重ねたもの。工具は板を突き抜けているので板の上下面は自由
- 刃は高さ z ごとに z·tan β / R だけ遅れて回る（下端が先に食い付く）。刃面はつる巻面で、距離関数の勾配に軸方向成分 ∂d/∂z を入れて法線を出す
- 出力：接線分力 Ft・半径分力 Fr（刃の各接触点の向きで分解して合計）・軸方向分力 Fa、切削係数（F = K·A + Ke·L を公称切取り面積 A と接触長さ L に最小二乗）、切りくず流出角 ηc
- 既定は φ2・3 枚刃・fz 0.1・ae 0.2・ap 0.3・ダウンカット・解像度 h/4（約 8,300 粒子、Node で 6〜7 分）。切りくずの厚さ方向に粒子が 4 個ないと切りくずが立ち上がらず刃に沿って滑るだけになる（h/2〜3 で確認）

## エンドミル：続けて削る刃と送りの軌跡（2D 断面）

「続けて削る刃の数」を 2 以上にすると、1 刃目が残した面（加工硬化・残留応力・実際の形）を 2 刃目が削ります。刃と刃の間の空転は飛ばし、前の刃の切りくずは取り除きます。グラフは刃ごとに続けて並べ、切削係数は最後の刃から求めます。

刃の中心は回りながら送りで進むので、前の刃の通った跡はトロコイドです。以前は前の刃の跡を止まった円で作っていたため、1 刃目の切取り厚さが送りの分だけ厚く（φ10・2 枚刃・ae 1 mm の出口で 60 µm に対し 72 µm）、力と Ktc が高めに出ていました。いまは前の刃も同じように進んだ跡で作るので、1 刃目と 2 刃目の力がそろいます（A7075 φ10 fz 0.1 アップ、h/4：ピーク 89.7 N の単独に対し、2 刃連続で 89.5 → 96.4 N。2 刃目は加工硬化した面を削るぶん少し高い）。3D のねじれ刃も、層ごとに同じずれを入れています。

切削係数の当てはめは、切取り厚さが最大の 15〜90 % の区間だけを使います。最大付近は刃が上面（自由面）に出入りするところで、アップカットでは出口で切りくずが離れて力が落ち、ダウンカットでは入口で衝撃が出ます。両端を入れると同じ材料でアップ 453・ダウン 1,100 N/mm² と倍以上違い、上端を外すと 1,217 と 1,143 にそろいました（最初の加工面の位置を直した後は 1,222 と 1,203）。Ktc と Kte の分け方はこの厚さの範囲では不安定なので、3軸加工シミュレーターへ渡すときは力そのもの（K·h + Ke）が合っているかで見てください。

3D のねじれ刃でも「続けて削る刃の数」が使えます（粒子数は約 2.3 倍、φ2・ap 0.3・h/4 の 2 刃で約 23 分）。前の刃の切りくずは、その刃のトロコイドの跡の内側（加工面から 1 粒子間隔より内側）にある粒子として取り除きます。最初は刃が止まった位置の円の内側を取り除いていて、跡の外まで（送りのずれの分）削ってしまい、2D の φ6 で 2 刃目が 13 % 低く出ていました（直して −5 %）。3D（A7075 φ2 β 30°、h/4）では 2 刃目の最大接線分力が 31.6 → 25.5 N と 2 割低く出ていました。h/6 でも −17 % で解像度のせいではなく、原因は 1 刃目のほうでした。粒子は工具面から接触距離（0.5 粒子間隔）離れて止まるので、刃が残す加工面は刃の軌跡より少し外側になります。最初の加工面は軌跡ちょうどに並べていたため、1 刃目だけ切取り厚さがその分厚かったのです（h/4 で約 2 割）。いまは最初の加工面も軌跡から 0.5 粒子間隔外に並べ、3D は 26.7 → 26.3 N（−1.5 %）、2D の φ6 ダウンは 77.6 → 81.0 N（+4 %、加工硬化した面のぶん）とそろいます。単独の 1 刃も同じだけ下がり、A7075 の Ktc はほぼそのまま、Kte が 16 → 11 N/mm になりました。

### 回し続けたときの工具温度

1 刃の計算は冷えた工具から始まるので、表の「工具の最高温度」は 1 回の接触で上がった分です。実際の加工では刃は 1 回転に 1 回だけ削り、残りは空転して冷えます。そこで、1 刃の接触で工具の各セルに実際に入った熱を 1 回転の時間で平均し、その熱を受け続けたときの定常温度を「回し続けたときの平均温度」として出します（A7075 400 m/min・φ6・ae 0.3：約 110 °C、S45C 200 m/min：約 100 °C）。接触のたびに表面は切りくず側の温度（約 480 °C）近くまで上がります。界面の熱伝達率を時間平均して解くと、熱伝達率が大きいため接触時間が短くても工具が切りくずの温度に近づいてしまい（同条件で 350 °C）、これは平均の取り方の誤りなので使っていません。

## 工具を温めてから削る（直交切削）

1 回の計算で削るのは 0.6 mm 程度（200 m/min で 0.2 ms）なので、工具はほとんど室温のままです。冷たい工具が接触面から熱を吸うので、切りくず側の温度も低く出ます。工具の定常温度は後半の平均接触条件から推定していますが、その接触温度自体が冷たい工具で冷やされた値でした。「工具を温めてから削る」をオンにすると、1 回目の定常温度を工具の初期温度にして 2 回削り直し、3 回目の結果を表示します（計算は 3 倍）。

S45C h 0.1 α5、h/8。削り直しの回数ごとの工具の定常最高温度 [°C]（3 回目と 4 回目の差は 10 °C 以内）：

| V [m/min] | 冷たい工具 | 1 回温める | 2 回 | 3 回 |
|---|---|---|---|---|
| 100 | 459 | 508 | 527 | 538 |
| 200 | 535 | 604 | 628 | 631 |
| 300 | 593 | 676 | 690 | 699 |
| 400 | 620 | 720 | 737 | 739 |

工具の温度は 80〜120 °C 上がり、200 m/min で 630 °C 程度になります（S45C を超硬で 200 m/min、f 0.1 で削ったときの文献のすくい面温度は 650〜700 °C 程度。目安の値で、条件ごとの照合はしていません）。kc と μ はほぼ変わりません（変化は ±2 %）。クレーター摩耗速度は 1.8〜2.3 倍になり、そこから出す Taylor 指数は 0.47 → 0.44 です。逃げ面の摩耗速度は最大値をとるので削り直しごとのばらつきが大きく（200 m/min で 0.47〜0.66 µm/min）、温めた工具では Taylor 指数を決めきれません。条件スイープは温めずに計算します。

ほかの材料（推奨速度、3 回温めたあと）：工具の定常最高温度は SUS304 518 → 574 °C、Ti-6Al-4V 650 → 806 °C、IN718 702 → 820 °C、A7075 351 → 約 400 °C。熱を通しにくいチタン合金で上がり方が大きく、kc の変化は 3 % 以内です。A7075 は延性破壊で切りくずがちぎれるので、温めなくても計算ごとに kc が ±10 % ほどばらつきます（一定の摩擦で 1,010 / 956 / 955 / 1,051 N/mm²）。破壊をオフにすると kc は約 1.4 倍になり、ばらつきは小さくなります。

## 刃先丸みの効き（直交切削）

S45C 200 m/min・h 0.1 mm・すくい角 5°・h/8 で、刃先丸み 2・10・20・40 µm：主分力（kc）は 1,993・2,025・2,056・2,206 N/mm²（+11 %）、背分力は幅 1 mm あたり 56・65・70・93 N（+66 %）。丸みが大きいほど刃先で押し付けてすき取る分が増え、主に背分力が上がるという実験の傾向と合います。

## すべり速度で変わる摩擦

切りくずが工具のすくい面を速くすべるほど接触面が熱くなり、摩擦は下がります（工具-切りくず間の摩擦の測定では、鋼と超硬で 50 m/min で 0.5 前後、300 m/min で 0.3 前後）。そこで摩擦係数を接触している粒子のすべり速度 v で変えています：μ = μ0·(v / vref)^−0.3（vref は材料の推奨切削速度の半分、およそそこでの切りくずの速さ。0.3〜1.5 μ0 に制限）。切りくずが工具に張り付く部分はもともとせん断流れ応力が上限なので、効くのはすべっている部分です。「摩擦の速度依存」を「なし」にすると一定の μ0 に戻ります。

S45C、h 0.1 mm、すくい角 5°、h/8：

| 切削速度 [m/min] | 60 | 120 | 200 | 300 | 400 |
|---|---|---|---|---|---|
| kc（一定の摩擦） | 2,024 | 2,014 | 2,025 | 2,052 | 2,044 |
| kc（速度で変わる摩擦） | 2,395 | 2,138 | 2,017 | 1,945 | 1,905 |
| 平均の摩擦係数 | 0.59 | 0.49 | 0.42 | 0.38 | 0.35 |
| 背分力比 Ft/Fc | 0.48 | 0.37 | 0.32 | 0.28 | 0.25 |
| 切りくず厚さ比 hc/h | 2.27 | 1.96 | 1.76 | 1.70 | 1.65 |

60 → 400 m/min で kc は 20 % 下がります。超硬工具の Kienzle の速度補正 (100/V)^0.1 だと 17 %。背分力比と切りくず厚さ比も速いほど下がり、実験の傾向どおりです。最初は接触温度で変える式（μ ∝ (Tm − T)^2.5）を試しましたが、アルミは切削温度が融点に近いので、流れ応力を校正すると温度が変わって摩擦が大きく動き、校正が収まりませんでした。

## STL 取り込み（任意の工具とワーク、3D）

「STL 取り込み」モードでは、工具とワークを閉じた STL（バイナリかテキスト）で読み込んで削ります（src/mesh.js、src/sph3d.js の mode 'mesh'）。座標はファイルのまま、z が上です。

- 工具は剛体です。三角形から BVH を作り、厳密な最近点距離と角度重みつき擬似法線の符号で符号つき距離を求め、粒子が近づいたところだけ 8³ セルのブロックに分けて（セルは粒子間隔の半分）標本化し、3 線形補間で引きます。法線は補間した距離の勾配ではなく最近点の向きを使います。
- ワークは x 方向の光線の偶奇で内側を判定して、粒子間隔で並べた粒子に置き換えます。下面から 3 層を固定します。
- 工具の動きは 3 通りです。「直進」は +x へ切削速度で進みます（平削り・形削り）。「回転＋横送り」は工具の外形の中心を通る z 軸のまわりに、一番外側の半径 R で切削速度になる角速度 ω = V / R で回り、1刃送り fz × 刃数 × 回転数で +x へ進みます。「回転＋下へ送り」は 1回転送り f で −z へ進みます（ドリル）。
- 回転する工具は、それまでに削ったはずの形（工具の回転の包絡を1刃分の送りだけ戻した形）をワークからくり抜いてから始めるので、最初の刃から定常の切りくずが出ます。直進する工具は自分の形だけくり抜きます。
- 工具に触れたあと、工具から 8 粒子間隔以上離れて止まった粒子は仕上がり面として固定し、次の刃が 3 間隔以内に来ると戻します。工具は断熱（摩擦熱の工具への分担は差し引くだけ）で、工具温度と摩耗は計算しません。
- 出力は工具が受ける力 Fx・Fy・Fz（ファイルの軸）、回転軸まわりのトルクと主軸動力、被削材の温度・ひずみ・応力・損傷の分布です。

例（ファイルなしで選べます。`node scripts/make-examples.mjs` で examples/ に同じ STL を書き出します）：

| 例 | 工具 | ワーク | 動き |
|---|---|---|---|
| 平削り | すくい角 5°・逃げ角 7° の刃、h = 0.1 mm | 1.0 × 0.4 × 0.4 mm | 直進 0.6 mm |
| エンドミル | φ2・2枚刃・ねじれ 30°、ae = 0.2 mm（刃がすぐ食い付く向きに回してある） | 1.4 × 0.25 × 0.15 mm（ap 0.15） | 回転＋横送り fz 0.1 mm、70°（1刃の通過） |
| ドリル | φ1・先端角 118°・2枚刃・ねじれ 30°、刃の後ろに逃げ | 1.4 × 1.4 × 0.55 mm（下面と側面を固定） | 回転＋下へ送り f 0.2 mm/rev、120° |

平削りの例（粒子間隔 25 µm = h/4）では、Fx が 0.3 mm ほどで −115 N 前後に落ち着きます。同じ解像度の 3D 傾斜切削（λ = 0、幅 0.4 mm、側面自由）は 120 N で、両者はそろっています。便覧の kc（2100 N/mm²）からの 84 N より 4 割大きいのは、切取り厚さに粒子が 4 個しかない粗さのためです（2D でも h/4 では kc が高めに出ます）。

回転する工具の力とトルクの平均は、刃が削っている間（力の大きさが最大の 1 割以上の区間）だけで取ります。エンドミルの例（A7075、300 m/min、間隔 20 µm）では主軸トルクの最大 13.9 mN·m、平均 7.3 mN·m。ドリルの例（S45C、200 m/min、間隔 30 µm）は、食い付き直後で推力 99 N・トルク 54 mN·m と、Kienzle の目安（0.5·kc·f·D·sin59° ≈ 90 N、kc·f·D²/8 ≈ 52 mN·m）にそろいます。ただしそのあとは 120° 回るまでに推力が 2.5 倍ほどに上がります。断面を見ると、刃の前の材料が切りくずとして離れず、円すい面に沿って押し上げられています。1枚の刃の切取り厚さ 0.1 mm に粒子が 3 個しかないためで、溝をねじっても、ワークを厚くして側面を固定しても変わりませんでした。ドリルの例は形と動きの確認用と考えてください。送り 0.2 mm/rev は実用より大きめですが、0.05 mm/rev では切取り厚さが粒子 1 個より薄く、まったく削れません。刃の後ろの逃げが1刃の送りより小さいと、逃げ面がこすって力が何倍にもなるので、自分のドリルを読み込むときは逃げも確かめてください。

注意：粒子数はワークの体積 / 間隔³ で、15 万個までです。小さな部分（刃先のまわり 1〜2 mm）だけを切り出したワークにしてください。計算は数分から数十分かかります。
